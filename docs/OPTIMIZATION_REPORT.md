# Football Prediction Research 优化验收报告

2026-11-22，本地分支 §refactor/monorepo-integration§。以集成提交 §fcef30bae889974fd830fd48b5e17f30681355a9§ 为对照。欧洲阶段验证通过后，再实施 Gulf 阶段。正式论文数据、冻结协议、配置和结果继续按原始来源保存。

## A. Architecture improvements

- 欧洲事件流水线分为 CSV 读取、按比赛分组、单场曲线汇总和输出。原有时间和比赛排序、计算公式、缺失特征列以及列顺序保留。入口可指定输入和新输出路径。
- Gulf 将 UTC 批次键构造、稳定排序和位置分段集中在 §temporal_batches§。调用方 Elo、Poisson/Dixon–Coles 和半场结构模型沿用原接口。
- 实验记录和性能比较放在根目录工具层。比赛级、事件级和 Gulf 的依赖、训练代码、模型定义和评价继续独立。

## B. Code quality improvements

- 欧洲用具名函数分离单场特征计算与文件 I/O，集中空曲线的特征名，使用带参数的日志。输入缺少第一半场比赛标识时提供明确错误。若输出路径已存在，入口拒绝写入。运行示例使用新输出路径。
- Gulf 保留 datetime parsing、同 UTC 日的 date-only 隔离、同一时间组内原始行序和位置数组类型。测试覆盖无精度列的日期回退、重复索引、混合时区、顺序和空输入。

## C. Performance improvements

| 优化 | 原瓶颈 | 实施 |
| --- | --- | --- |
| 欧洲第一半场特征 | 每个比赛 ID 都对完整的上半场表构造布尔条件，重复扫描 3,206,912 行 | 复用已有排序，一次识别相邻比赛边界，再按连续区间切片 |

## D. Reproducibility improvements

- §scripts/record_run.py§ 以项目和实验 ID 为新实验分配独立目录。起始文件记录声明的运行命令、输入路径和 SHA-256、配置、模型参数、随机种子、协议、指标名、解释器、包版本和 Git 状态。完成文件记录退出码、实际输出哈希和可选的 metrics JSON。
- 结束时复查输入字节、路径解析目标及 Git 状态。发现漂移会记录 §invalid§。从含未提交改动的工作树运行会标记代码溯源未经验证。记录工具采用 opt-in，现有训练入口保持独立。 [运行记录用法](reproducibility.md#experiment-receipts)
- 原始迁移清单保留。两处经审核的 Python 文件另外登记集成与优化 SHA-256。校验覆盖原始源、当前工作树和本地资产，并检查本地资产的 Git 索引排除。 [优化哈希记录](provenance/optimization-overrides.json)

## F. Before/After benchmarks

Windows x64 CPython 3.11.9。两个阶段均使用项目验证环境及同一份已授权的本地输入。分别在改动前、后测量，每组首轮作为预热。以下均为有效样本的中位数。

| 阶段与计时边界 | 重复数 | Before | After | 比值 |
| --- | ---: | ---: | ---: | ---: |
| 欧洲全部 6,360,215 行事件数据，CSV 读取至新 CSV 写出 | 4 次/版本，3 次入中位数 | 12.87554 s | 7.07530 s | 1.82×，耗时下降 45.0% |
| Gulf 5,499 场的时间批次生成，输入表已加载 | 8 次/版本，7 次入中位数 | 635.29190 ms | 6.95750 ms | 91.3×，该步骤耗时下降 98.9% |

欧洲四次原版采样为 13.34646、12.99789、12.72911、12.87554 秒，优化后为 6.70444、6.87775、7.07530、7.13803 秒。Gulf 在同一基准进程复跑 8 次后，两个中位数为 667.77 和 6.95 毫秒，输出批次哈希一致。Gulf 的速度比仅适用于时间分组，训练与端到端运行未作速度归因。没有测量峰值内存。 [复跑命令](reproducibility.md#benchmark-the-optimized-stages)

## G. Experimental consistency verification

- **欧洲数据与特征。** 两个版本均得到 1,823 × 24 的 CSV。四次输出均与存档逐字节相同，SHA-256 为 §bfac7235d3882337bdcdf288be7757f6db6eb7c0ee5614038a3539c9c70a5627§。五联赛、三个时间分区及四种条件的 60 组模型输入和标签逐值一致。England CatBoost 小样本对照采用同一固定参数、训练样本与 76 场测试数据，概率最大绝对差为 0.0，Accuracy 和 Log Loss 相同。
- **Gulf 数据、时间与预测。** 5,499 行得到 4,049 个批次，成员、位置顺序及分组哈希完全相同，SHA-256 为 §75f8f403463be802baebba91af86cc4fb9aa021a358322df75d77453744bb7b8§。五个外折和二十个内折保持相同。对照 Experiment A 的开发 smoke，15 行预测、类别、列顺序与计算指标完全相同，概率最大绝对差为 0.0。
- **冻结结果。** 2,789 场 Gulf 冻结预测复算中，C030 的 Tied-Zero − Zero Accuracy 差为 −0.014700609537，Log Loss 差为 +0.010244322402。比较存档聚合值使用绝对容差 §1e-13§，只吸收 CSV 读入与求和顺序的双精度舍入。代码变更前后批次、CSV 和已运行预测比较均要求精确一致。
- **文件保护。** 源与目标清单核验 2,312 项，0 差异。2,163 项本地研究数据和结果均保留在 Git 索引之外。两个源仓库的 HEAD、origin 和干净工作树在验收时复核。
