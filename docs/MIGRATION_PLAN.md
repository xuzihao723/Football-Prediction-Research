# Football-Prediction-Research 迁移计划

当前阶段到本文档为止。以下工作待新阶段授权后执行。保护原始快照，将可重放的历史结果与方法修正分开交付，之后由用户决定新独立 GitHub 仓库的创建与推送。

| 优先级 | 工作 | 理由 |
|---|---|---|
| P0 | 欧洲正式论文版本和折清单、调参切分与预处理、排名索引、事件 OOF | 影响历史结果归属或方法有效性。 |
| P0 | 海湾冻结产物依赖图、数据许可与代码授权、所有正式运行入口 | 决定能否重放及公开发布。 |
| P1 | 独立包、工作目录可移植、信息时点与概率契约、离线复算和测试 | 确保可安装、可核对、可扩展。 |
| P2 | 减少重复 IO/内存、结构化日志、类型覆盖和汇报 | 在基线可对账后优化。 |

- [ ] 取得 IJOCTA 修订稿对应的正式三折 + 2024/25 生成脚本、逐场预测、标签、分折清单、候选配置和试点 374 测试键。核对排除 Spezia–Hellas Verona 的确切规则。保留 `all_results.json` 及 `search_spaces.json` 为历史基线，并单独登记后者的 ZIP 来源字段。
- [ ] Gulf 核对 `tools/final_design_execution.py` 缺失的回放输入、v4 协议与定稿关系，以及从源数据到 harmonized 的版本、补录规则和准确率主指标版本。审核 frozen 结果的保留粒度，逐一判定再分发权限。
- [ ] 获取版权人发布授权、StatsBomb、FootyStats、Football-Data 和补录来源的条款适用性、赔率使用范围与论文公开政策。许可未明确的样本在作者受控目录保留，公共清单写来源、schema 和获取方式。数据内容准入规则见 [数据与许可审计](DATA_AND_LICENSE_AUDIT.md)。
- 验收要求为每个拟迁移条目都有角色、来源、处理结果与缺口。缺失稿件产物可标记为待定位，相关论文复现状态保持可见。

## 2. 迁移成可安装的项目边界

- [ ] 在目标目录独立初始化 Git，设置文件忽略和发布白名单。记录代码来源、作者归属和许可。目标 Git 工作区由新的历史管理，两个原始仓库保有原 Git 元数据。新远程由用户创建。
- [ ] 按 [架构设计](ARCHITECTURE_DESIGN.md) 建三个 `pyproject.toml`、约束文件、`src/`、`configs/`、`tests/`。先逐组件复制已准入的脚本与配置，再做可机械核对的 `src.*`→具名包迁移，写旧到新路径表。Europe 两套入口分别验证，Gulf 保留 A–E、v4、定稿三组入口。
- [ ] 给 M 的 data loader、ETL、tuning 以及 E 的采集和 Optuna 显式 data/output root。清除 import I/O，保留 CLI 默认方法。Gulf 的 `src/config.py` 和工具入口注入 paths，限制 `freeze()` 清点范围到显式输入。整理读/写清单和错误信息。
- [ ] 每组件单建环境，安装固定运行依赖和测试依赖。跑导入和 `--help`，从项目外 cwd 验证，检查退出码与无网络、无写入。按实际导入与可选后端决定约束。
- 验收要求为三个包各自可构建 wheel 和安装，互不依赖其他组件的 `src`、cwd 或内部目录。所有新输出进入显式可写工作目录。

## 3. 先恢复无训练的数字链

- [ ] 分项目生成不可变产物清单。`legacy` 引用欧洲根 JSON 和海湾旧 A–E，`paper-frozen` 引用核实后的逐折、逐场与定稿摘要。保留 byte hash、列顺序、方法标签、原始对照方向和独立的派生映射。
- [ ] Gulf 核查 `results/final_results/canonical_prematch_oos.csv`、`tied_zero_lr_oos.csv` 等是否是缺失旧路径的同一输入。用 SHA（若有）、fold、actual class、method、representation 和 ordered fixture keys 对照。将 final tools 的输入映射配入配置。 `analyze_xgb_v4.py` 概率/对比与 SHAP 部分独立触发，缺少档案时给出所需路径。
- [ ] 写只读指标与表格入口。对 Gulf 校验 2,902/2,789 两种分母、七学习器 39,046 行与 PRE/HT matched keys，逐方法重算 accuracy、LL、Brier、Macro-F1 和指定分箱 ECE。使用冻结 C030 与 已观测的最大概率行和误差设断言，CSV 舍入容差在复算报告说明。对发布所需表和图建立逐项 input/config/output 记录，核对主指标和 Holm 家族元数据。
- [ ] 对欧洲保留历史摘要的分折指标和配置。只在取得正式预测后核对稿件表格数字、平均方法、校准、按时序块成对推断及 2024/25 持出。正式预测缺失的行标注证据限制。
- 验收要求为无需训练可生成已获冻结输入支持的表，并逐项列出缺失输入。报告与图的生成阶段不能修改原始输入。

## 4. 以独立协议修正实验风险

- [ ] 欧洲 `tune_hyperparameters.py` 改用显式 train/valid 索引，将缺失率筛选、补值、选择、缩放与采样置于内折训练；保留历史协议证据。对排名用 fixture key 或原始索引写回，记录修正前后受影响行。处理同时间比赛、赛季边界、赔率观测时间和可用列。
- [ ] 欧洲 E 的动量用途只在合法截止点内取样；为 name/date join 增加键、映射和冲突日志。删除后期模型生成早期 OOF 的执行路径时，在修正协议中用 warm-up 明示缺失处理，追踪新旧样本覆盖。按版本登记赔率字段，复合曲线归入半场信息集。
- [ ] Gulf 收拢正式评估入口的锁和 manifest。建立 odds 缺失、date-only、新赛季、同时开赛、失败/停止分支以及 OOF warm-up 的测试。对训练数据设置 HPO 候选、允许列校验、日志和概率列顺序，记录数值精度策略。
- [ ] 在历史产物已对账后，对 event parquet 读列/分区和 Gulf 预先分桶做同输出差分和资源基准。保留原始方法与历史结果，将任何变化的指标写入 `corrected` 独立目录。

## 5. 测试矩阵与发布交接

| 测试 | 迁移验收标准 |
|---|---|
| 三套环境与 CLI | 分别构建安装，Windows 和 Linux 目标环境从仓库外导入和调用帮助，导入无数据访问、写盘或训练。 |
| 时间切分与数据隔离 | 欧洲核对固定历史、正式 3 折+持出和事件 60/20/20 各自的协议；Gulf 验证 5 折、高精度与 date-only 隔离。每折用键断言无重叠、训练特征来源早于预测，同时间列表调整顺序不改变历史特征。 |
| PRE/HT/事件可用性 | 人工合成跨赛季重置索引、同时间比赛、未来赛果、负时间、半场补时、重复 provider key、缺赔率和不合法列。测试事件前缀不随未来事件变化，早期 OOF 缺失不回填，HT 比分只在 HT 生效。 |
| 预处理与类别 | 改变验证/测试的均值与缺失率不能影响拟合后的特征；极端缺失、缺类别、错序概率、负概率、NaN、超容差行能被正确处理或拒绝。测试 staged feature lists 和一级/二级模型的时间拟合顺序。 |
| 海湾模型与统计 | 现有 `test_temporal`、`test_data`、`test_zero_anchor`、`test_xgb_v4*`、`test_final_design`、runner、smoke 及其他测试逐套标记数据和拟合需求；验证 Fixed A=I、KL 端点、SHAP 重构、OOF null case、配对、bootstrap、Holm 和概率校准。 |
| 冻结回归与 CI | 重新计算已准入概率表，在预先记录的容差内匹配稿件或归档表。合成 fixture 独立运行。检查 CI 不读取私有路径、不联网取数据、不写冻结目录，新产物携带 manifest。 |
| 用户批准的完整复现 | 独立环境记录 seed、线程、数据/代码哈希、runtime，跑已确认的三套正式流程；逐表核验偏差。Gulf 开启正式外测依原双条件；真数据及训练套件在明确授权后运行。 |
